# BuildLink

Responsive front-end prototype for a construction resource marketplace.

## Included
- Materials exchange listings
- Open plots and site rentals
- Labour and Mukadam/team availability category
- Engineers, architects and specialist jobs
- Freelance services, AutoCAD, BOQ, plumber and electrician categories
- Search, category and location filters
- Embedded Google Maps view and browser geolocation
- Post-listing form, local browser storage and WhatsApp contact

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to deploy. The URL will be:
   https://narendraP12.github.io/buildlink/

## Important prototype limitations
This is a front-end demo. Sample listing phone numbers and listings are illustrative and must be replaced. New listings are stored only in the browser where they are posted; users do not yet share a common database. Real multi-user accounts, secure authentication, admin moderation, image uploads and shared listings require a backend/database integration. The basic embedded map is displayed inside this site; advanced custom map pins and directions may require Google Maps Platform configuration.
